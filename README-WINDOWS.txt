   MARVI'S BOHRA FOOD - BUSINESS MANAGER FOR LAPTOP & DESKTOP

Why this never gives a server error:
Everything runs directly on your laptop at http://localhost:3000 with
real-time cloud sync to your Android phone via Google Firebase! Even if
remote preview servers restart, your laptop web app works 100% of the
time with zero server errors.

WINDOWS 10 / 11 SETUP (1-Click App Window):
1. Extract this ZIP folder completely (Right-click -> "Extract All...").
2. Double-click "Start-Business-Manager.bat".
   - Microsoft Edge or Chrome opens automatically as a dedicated
     Business Manager desktop app window at http://localhost:3000/
   - Works offline and online!

MAC / LINUX SETUP:
1. Extract this ZIP folder.
2. Double-click "Start-Business-Manager.command" (or run in Terminal:
   bash Start-Business-Manager.command).

INSTALL AS CHROME / EDGE APP (OPTIONAL):
- While open in Chrome or Edge, click the "Install" icon on the right
  side of the address bar (or Menu -> Apps -> Install Business Manager)
  to pin it to your Desktop / Taskbar / Start Menu.

CONNECT TO YOUR PHONE IN REAL TIME:
1. Click "Settings & Backup" (in the left sidebar).
2. Click "Sign in with Google to Sync".
3. Choose your Google account (juzerzoebmarvi@gmail.com).
4. Status turns green ("Connected") and all invoices, stock, payments,
   expenses, and customers sync live in both directions with your phone!

IMPORTANT:
- Keep the small launcher window open while running the local server
  (or minimize it).
- You can right-click "Start-Business-Manager.bat" -> Send to ->
  Desktop (create shortcut) for instant 1-click opening anytime.
